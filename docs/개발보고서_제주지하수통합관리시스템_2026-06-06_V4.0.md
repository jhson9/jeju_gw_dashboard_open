```python
def _m_slot_window(m_slot: dict):
    """periods["M"] 슬롯 기준 일별 차트 윈도우 반환."""
    if m_slot.get("partial"):
        return (..., end_date.day, ...)        # 1 ~ (D-1)
    if m_slot.get("half"):
        return (..., 15, ...)                  # 1 ~ 15
    # full: 1 ~ 말일
    return (..., calendar.monthrange(...)[1], ...)
```

## 5. 캐시 키 안정화 (H5+M2)

### 문제

`_cached_gwlevel_diff_dict(ws_data_all, periods, n_years)` 가 `periods` dict 를 직접 인자로 받음.
- `periods["base_date"]` 는 `datetime.date`, `periods["mode"]` 는 `str`, 슬롯 3개는 `dict`.
- Streamlit 의 default dict 해시는 nested datetime + 가변 키 조합에서 잠재 불안정.
- 또한 dict identity 만 비교될 위험 → 같은 객체에 값만 바꿀 때 무효화 안 됨.

### 해결

```python
def _make_periods_key(periods: dict) -> str:
    parts = []
    for k in ("M-2", "M-1", "M"):    # 화이트리스트 슬롯
        p = periods.get(k)
        if not isinstance(p, dict):
            continue
        end_d = p.get("end_date")
        end_s = end_d.isoformat() if hasattr(end_d, "isoformat") else str(end_d)
        parts.append(f"{k}:{p.get('year')}-{p.get('month'):02d}"
                     f"-p{int(bool(p.get('partial')))}"
                     f"-n{p.get('n_days') or 0}"
                     f"-e{end_s}")
    bd = periods.get("base_date")
    parts.append(f"base:{bd.isoformat() if hasattr(bd, 'isoformat') else bd}")
    parts.append(f"mode:{periods.get('mode')}")
    return "|".join(parts)

@st.cache_data(ttl=600, hash_funcs={pd.DataFrame: id})
def _cached_gwlevel_diff_dict(ws_data_all: dict, periods_key: str,
                              n_years: int, _periods: dict) -> dict:
    # _periods 는 `_` prefix → Streamlit hash 제외 (공식 규약)
    return watershed_mapper.compute_gwlevel_diff_dict(ws_data_all, _periods, n_years)
```

### 효과

- 캐시 키: `ws_data_all(id) + periods_key(str) + n_years(int)` — 모두 hashable
- `_periods` 는 사용용으로만 전달, 캐시 분리 영향 없음
- 동일 base_date/mode/슬롯이면 캐시 히트, 한 필드라도 다르면 즉시 무효화

### 수학적 진단 (사전 분석)
