# 공개판 (Compact_Open) 구성 안내 — 2026-06-11

## 1. 개요

- **원본**: `jeju_groundwater_dashboard` (메인 V3) → **단방향 sync** (공개판 → 메인 역방향 금지)
- **목표**: Git LFS 없이 100% 무료 운영 (단일 파일 100MB 미만, 총 추적 용량 ~76MB)
- **탭 구성**: 01~04 (강수/지하수위) · 11~13 (관정) · 21~23 (이용량) · **32·34 (드론 2D)** · 41~43 (농업) · **51 (챗봇)** · 데이터 관리

## 3. 공개판 전용 코드 패치 (메인 V3 와 다른 부분)

1. `app.py` — 드론 그룹을 32·34 두 탭만 등록.
2. `_drone_helpers.py` — `is_cloud_env()` 추가. Cloud 에서 `url_for_preview()` 가
   **base64 data URI** 반환 (pdf_server·GitHub raw URL·LFS 불필요 → repo 이름 무관).
   `_hd_preview_builder()` 는 Cloud 에서 동봉 PNG 그대로 사용.
3. `tab32_drone_2d.py` — `preview_path()` 우선 사용 (V1.2.6 패턴).
4. `tab34_drone_diff.py` — Cloud 에선 viewer html 을 **인라인 렌더**
   (`diff_viewer_dod_inline_html`, 이미지 data URI 임베드, 약 15MB).
   DSM 실파일 없으면 DoD 자동 비활성.
5. `diff_viewer_dod.html` — `window.__PARAMS__` 지원 + HD 타일 없으면 PNG 자동 활성.
6. `data/04_drone/registry.json` — 덕천 2미션만, `tiles_3d/dsm/pointcloud` available=false.

## 4. Streamlit Cloud 배포 시

1. Secrets 에 `VWORLD_API_KEY` 설정 권장 (배경지도 HD) — 없어도 기본 동작.
2. requirements.txt 는 챗봇 무거운 의존성(ollama·chromadb·sentence-transformers) **미포함** — Cloud 빌드 가볍게 유지.
3. 데이터 갱신 후엔 Manage app → **Reboot** (`@st.cache_resource` 캐시 해제).
4. LFS 미사용이므로 bandwidth 비용 0 — 7월 1일 budget $0 변경과 무관하게 안전.
