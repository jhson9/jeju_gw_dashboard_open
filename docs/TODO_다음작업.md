## 🚧 다음 작업: 모바일 반응형 대응

### 배경
PC 환경에서는 잘 보이지만, **삼성 태블릿 S10+ / 갤럭시 S23 휴대폰에서는 가독성이 떨어짐**. 외부 사용자가 다양한 디바이스로 접근하므로 모바일 대응이 필요.

### 추천 경로: **Path A — CSS 반응형**

작업량 1~3시간으로 60~70% 개선 가능. 태블릿(S10+)은 거의 데스크톱 수준으로 잘 보이게 되고, 휴대폰(S23)도 차트는 보이고 표는 가로 스크롤로 처리.

### 구체 작업 목록 (Path A)
1. **헤더 행 반응형**: 날짜 입력 3개(연/월/일) + 분석 버튼 → 폰에선 세로 stack
2. **탭 라벨 줄임**: "📋 대시보드 요약" → 폰에선 "📋" 아이콘만
3. **차트 자동 크기**: 모든 Plotly 차트에 `use_container_width=True` 점검
4. **표 가로 스크롤**: 14수역 표는 `overflow-x: auto` 컨테이너로 감쌈
5. **폰트·여백 축소**: 모바일에서 패딩/마진 절반으로
6. **viewport meta 태그**: 모바일 브라우저가 스케일 안 하게

### 대안 (Path B/C는 보류)
- Path B (디바이스별 레이아웃): 1~2일 소요, 유지보수 복잡 → 일단 보류
- Path C (모바일 전용 앱 분리): Path A 후에도 부족하면 추가 검토
