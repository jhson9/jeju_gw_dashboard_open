## 4. 🎯 드론 분석·비교 품질 향상 제안 (DoD)

현재 구현 골격(공통 grid 재투영 → 전역 median 편향 보정 → 3×3 median filter → threshold 마스킹 → 통계·부피·PNG)은 실무적으로 잘 잡혀 있음. 다음을 추가하면 **정량 신뢰도**가 한 단계 올라감:

| # | 제안 | 난이도 | 요지 |
|---|---|---|---|
| Q1 | LoD95 (최소 탐지 한계) 자동 산출 | **하** | 안정영역 σ 기반 `LoD95=1.96·√(σ₁²+σ₂²)` → 임계치 기본값·범례 표시. meta의 rmse_m으로 1차 근사 가능 |
| Q2 | 부피 불확실도 표기 | **하** | 부피 ±오차(LoD×면적)를 통계카드에 부기 — 보고서 인용 가능한 수치化 |
| Q3 | Δz 히스토그램 + threshold 라인 | **하** | 임계치 선택 근거 시각화 |
| Q4 | hillshade 오버레이 | **하** | DoD 아래 지형 맥락 제공 |
| Q5 | DoD GeoTIFF 보존 | **하** | 현재 PNG만 저장 → Δz GeoTIFF 동시 저장 시 GIS 후처리·감사 가능 |
| Q6 | 수평 co-registration (Nuth & Kääb) | 중 | 탱크 가장자리 halo의 **근본 원인**(수평 오프셋) 보정 — 현재는 median filter로 증상만 완화 |
| Q7 | 안정영역 기반 robust plane-fit 편향 보정 | 중 | 실제 변화 면적이 클 때 전역 median 왜곡 방지 (diff.py 주석에 계획만 존재) |
| Q8 | 식생 마스킹 (ExG 지수 토글) | 중 | 계절 식생 변화 오검출 차단 |
| Q9 | 변화 patch 목록화 (connected-component) | 중 | 면적·부피·좌표 표 + "다음 변화 지점" 순회 |
| Q10 | 단면 프로파일 (선 긋기 → before/after 표고) | 중 | 기존 측정도구·DsmSampler 재활용 가능 |

**실무 적용 예시**: 저수조 침하 모니터링 보고 시 Q1+Q2를 적용하면 "Δz −0.08m (LoD95=0.05m 초과 → 유의미한 침하), 부피 변화 −12.3±2.1㎥"처럼 통계적 근거가 있는 수치를 보고서에 직접 인용할 수 있습니다.
